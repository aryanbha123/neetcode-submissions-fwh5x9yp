## About

This repository is filled automatically by NeetCode's GitHub Sync feature: each solution I submit on NeetCode is committed here. It covers **30 problems** from the NeetCode DSA roadmap, all written in **Java**. Many problems have several submissions, which show how a solution was refined over attempts.

## Repository Structure

```
Data Structures & Algorithms/
  <problem-slug>/
    submission-0.java   # first submission
    submission-1.java   # later submissions
    ...
```

Problem folders use NeetCode's slugs (for example, `two-integer-sum-ii` is LeetCode's "Two Sum II"). Submission numbers come from NeetCode, so gaps in the numbering are normal.

## How to Use

- Browse a problem folder and open the highest-numbered `submission-N.java` for the latest attempt.
- Each file is the class body submitted on NeetCode (a `Solution` class), so paste it into the matching problem on [neetcode.io](https://neetcode.io) to run it.
